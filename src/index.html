Resolution
Lower resolution = much smaller file. Halving the height (1080p → 540p) quarters the pixel count, so it is the single biggest size lever. Downscaling is irreversible — detail and text become permanently softer.

Bitrate fixes the file size, not the quality. The encoder must hit this number, so busy scenes get blocky when it is too low. Quality (CRF) mode is usually the better choice unless you need to land under a hard upload limit.
